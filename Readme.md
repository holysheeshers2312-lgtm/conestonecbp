# ConeStone CBP

Premium restaurant site for ConeStone CBP / Amma Kitchen (Changi Business Park).

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run start` — serve production build
- `npm run lint` — ESLint

## Notes

- Menu data lives in `src/data/menu/` (source: booklet PDF).
- Design direction: `DESIGN.md`
- Branch: `DEV`
