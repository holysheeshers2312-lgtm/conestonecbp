# Restaurant Website — Project Overview

Build a modern, responsive restaurant website with a **simple, professional, and elegant design**. The website should feel polished and welcoming without excessive animations, visual clutter, or unnecessary complexity.

## Design Direction
- Clean layouts with consistent typography, spacing, and colors.
- Professional food photography and an attractive menu presentation.
- Subtle, purposeful animations and smooth transitions.
- Fully responsive across desktop, tablet, and mobile.
- Accessible navigation and readable content.

## Website Sections
- **Home:** Welcoming hero section with a clear introduction.
- **About:** Restaurant story and introduction.
- **Menu:** Organized food and beverage categories, with accurate item names, descriptions, and prices.
- **Gallery:** A selection of restaurant and food images.
- **Contact:** Location, opening hours, and contact details, where verified information is available.
- **Footer:** Essential links and restaurant information.

## Menu Source
Use the restaurant menu PDF as the source of truth.

## Development Approach
Use the existing project's structure and technology stack wherever practical. Keep the code maintainable, use reusable components, and prioritize performance, accessibility, SEO, and a consistent user experience.

Follow an approval-first Spec-Driven Development approach: inspect the existing project, prepare a clear implementation proposal, incorporate feedback, and begin development only after explicit approval of the final proposal.

## Expected Outcome
A polished, professional restaurant website that presents the restaurant and its menu clearly, works smoothly across devices, and uses subtle animations to enhance—not distract from—the experience.
